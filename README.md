# WBS Donasi Masjid

Aplikasi Web-Based System (WBS) Donasi Masjid dikembangkan menggunakan Laravel untuk membantu pengelolaan donasi masjid.

## Teknologi
- Laravel
- PHP
- Supabase

## Instalasi

1. Clone repository.
2. Install dependency:

   `composer install`

3. Salin `.env.example` menjadi `.env`.
4. Generate application key:

   `php artisan key:generate`

5. Sesuaikan konfigurasi database pada `.env`.
6. Jalankan aplikasi:

   `php artisan serve`
